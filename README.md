# Pingu AI

Pingu AI is a modern AI chat website powered by Gemini 3.8 Flash.

## Features

- Gemini 3.8 Flash
- Google Search grounding
- Chat history
- New chat
- Mobile responsive UI
- Dark Liquid Glass interface
- Vercel Serverless Function
- API key protected on server
- No API key in frontend

## Deploy

1. Upload this project to GitHub.
2. Import the repository into Vercel.
3. Open Vercel Project Settings.
4. Open Environment Variables.
5. Add:

GEMINI_API_KEY

6. Put your Gemini API key as the value.
7. Deploy or redeploy the project.
